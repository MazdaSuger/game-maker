# 📖 ノベルメーカー (NovelMaker)

ノベルゲーム特化の **ノーコード** デスクトップ制作ソフト（Python + PySide6）。
プログラミング不要で、コンポーネントを並べるだけでノベルゲームを作成し、
その場でテストプレイできる **エディタ＋プレイヤー一体型** アプリです。
作ったゲームは **単体HTML/JS** に書き出してブラウザで配布でき、本体は
**Mac / Windows の実行ファイル** にもパッケージできます。

![editor](docs/editor.png)

## ✨ 対応機能

| 機能 | 説明 |
|------|------|
| 🧩 ノーコード編集 | シーンにコンポーネント（コマンド）を並べて物語を作成。**ドラッグ&ドロップで並び替え** |

| 🧑 キャラ・表情差分 | キャラごとに複数の表情（立ち絵）を登録・切替。**1画面に最大3人（左/中央/右）を個別配置** |
| 👤 主人公の立ち絵 | プレイヤー操作キャラは立ち絵を非表示にして名前だけ表示にできる |
| 🔢 変数管理 | 数値 / 文字列 / 真偽の変数。セリフに `{変数名}` で埋め込み |
| 🌐 システム変数 | プレイをまたいで共有・永続する変数。各エンディングの解放回数も自動記録 |
| 🔀 分岐 | 選択肢分岐 / 条件分岐（AND・OR の条件式ビルダー付き） |
| 🚩 フラグ＆ジャンプ | シナリオ内に「フラグ地点」を作り、条件付きでそこへジャンプ（ループ/分岐） |
| 🔤 名前入力 | プレイヤーに名前などを入力させ、文字列変数に格納 |
| 🎵 BGM | 再生 / 停止・ループ・**フェードイン/アウト** |
| 🔊 効果音(SE) | BGMとは別系統で効果音を一度だけ再生 |
| 🎒 アイテム管理 | 入手 / 使用 / 破棄。使用で消費するか切替。絵文字＋PNG画像、入手演出 |
| 🌑 暗転・背景管理 | 背景切替、暗転 / 解除（UIごと消す指定も可） |
| 🌅 CG | イベント絵（CG）を画面全体に表示 / 非表示 |
| 📊 数値ゲージ管理 | 好感度などのゲージ（最小/最大/色/表示） |
| 🎞 エンドロール | 縦スクロールのスタッフロール（スキップ可/不可を選択） |
| 🏁 エンディング管理 | 通常エンド + **裏エンド（隠し要素）** |
| 💾 マニュアルセーブ | **10スロット** の手動セーブ / ロード |
| 🏠 タイトル画面 | はじめから / つづきから。**配置の変更・ロゴ画像**にも対応 |
| 🎨 レイアウト編集 | 各コンポーネントの**表示位置をドラッグで配置**・個別**非表示**・**画像でカスタム** |
| 🔡 フォント変更 | フォント名選択／**フォントファイル(.ttf/.otf)取り込み** |
| 🗺 フローチャート | シーンと分岐（選択肢/条件/移動/エンディング）を図で可視化 |
| 📂 プロジェクト一覧 | アプリ内で最近のプロジェクトを一覧表示して開ける |
| ▶ 選択シーンからテスト | シーン一覧で選んだシーンから即テストプレイ |
| 🌐 ブラウザ書き出し | 単体HTML/JSに書き出してブラウザで配布（Cloudflare用ZIPも） |
| 📝 ブラウザ版エディタ | iPad等のブラウザで `.nvproj` を読み込み・編集・テスト・書き出し |
| 💿 アプリ配布 | 本体を Mac universal DMG / Windows EXE に書き出し（CI対応） |

## 🚀 セットアップ & 起動

```bash
# 依存をインストール
pip install -r requirements.txt

# 起動
python run.py
```

> Linux のヘッドレス/最小環境では Qt 実行に追加ライブラリが必要な場合があります:
> `libegl1 libgl1 libxkbcommon0 libdbus-1-3 libxcb-cursor0` など。
> 日本語表示には `fonts-noto-cjk` の導入を推奨します。

## 🎮 使い方

1. **シーン** タブで物語の場面（シーン）を作る。
2. シーンに「＋ コンポーネント追加」でセリフ・背景・分岐などを並べる。
   （シーンもコンポーネントも **ドラッグ&ドロップで並び替え** できます）
3. **キャラ・表情 / アイテム / 変数 / システム変数 / ゲージ / 背景 / CG / BGM / SE /
   エンディング** タブで素材を登録する。
4. **レイアウト** タブで表示位置・画像・非表示を、**設定** タブでフォント・タイトル等を調整。
5. ツールバーの **▶ テストプレイ**（F5）でその場でプレイ。
   シーン一覧の **▶ このシーンからテスト** で途中から確認も可能。
6. **ファイル → 保存** でプロジェクト（`.nvproj`）として保存。

## 🏠 タイトル画面（はじめから / つづきから）

ゲーム開始時に **タイトル画面** が表示されます。

- **はじめから** … 最初からプレイ
- **つづきから** … セーブデータがあれば、ロード画面を開いて再開
- プレイ中メニューの **タイトル**／エンディングの **タイトルへ戻る** でいつでも復帰

**設定** タブで次を指定できます（デスクトップ版・ブラウザ書き出し版に反映）。

- タイトル画面の **背景 / BGM**
- **タイトルロゴ画像**（指定すると文字の代わりにロゴを表示）
- **タイトル文字・ボタンの配置**（レイアウトタブの「タイトル文字 / タイトルボタン」をドラッグ）

## 🧑 立ち絵（最大3人）と主人公

- セリフの **「立ち絵の位置（左/中央/右）」** で、1画面に最大3人を並べられます。
  一度出した立ち絵は **キャラ退場** するまで残ります。
- **キャラ・表情** タブでキャラを「主人公（プレイヤー操作キャラ）」にすると、
  そのキャラは立ち絵を出さず **名前だけ** 表示します（立ち絵を出す設定も可）。
- セリフ個別に **「このセリフでは立ち絵を表示しない」** を指定することもできます。
- レイアウトタブで **立ち絵(左/中/右) の位置・大きさを個別に** 調整できます。

## 🎨 レイアウト編集（位置・非表示・画像・フォント）

**レイアウト** タブで、各コンポーネントを **ドラッグで自由配置** できます。

- 対象：セリフ枠 / 立ち絵(左・中・右) / 選択肢 / ゲージ / アイテムボタン /
  メニュー / タイトル文字 / タイトルボタン
- 位置は画面サイズに対する割合で保存され、どの画面サイズでも崩れません
- **コンポーネントの非表示**：セリフ枠 / 立ち絵 / ゲージ / アイテム / メニューを
  チェックで個別に隠せます（途中で出し入れしたい場合は「コンポーネント表示・消去」コマンド）

同じタブで **コンポーネントの画像取り込み** ができます。

- セリフ枠 / 選択肢ボタン / タイトルボタン / アイテムボタン /
  **名前入力の枠 / 名前入力の入力欄** の背景に画像を設定（引き伸ばし表示）

**フォント** は **設定** タブで変更できます。

- システムフォント名の選択、または **取り込みフォント(.ttf/.otf)** を指定
- ゲーム画面・ブラウザ書き出しの両方に適用されます

## 🚩 フラグ（指定位置）とジャンプ

- **フラグ地点** コマンドでシナリオ内に目印（名前付きの位置）を作ります。
- **フラグへジャンプ** コマンドで、同名のフラグ地点へジャンプします
  （現在のシーンを優先し、無ければ全シーンから検索）。
- ジャンプには **任意の条件** を付けられるため、変数と組み合わせて
  **ループ** や **条件付きの飛び先** を1シーン内で作れます。

## 🌐 システム変数（ゲーム全体で共有・永続）

通常の変数はプレイのたびに初期化されますが、**システム変数**は
**プレイをまたいで保持**されます（クリア回数・解放フラグ・周回数など）。

- **システム変数** タブで定義（数値/文字列/真偽）。`setVar` や条件、`{名前}` で
  通常変数と同じように使えます（書き込むと自動で永続化）。
- **各エンディングの解放回数を自動記録**。条件の「エンディング到達回数」で
  「このエンドを N 回見たら別ルート解放」などの分岐ができます。
  （回数はプレイ画面には表示されず、システム変数タブで確認します）
- システム変数タブで現在の解放回数・値を確認、**リセット** も可能。
- 保存先：デスクトップは `<プロジェクト>.system.json`、ブラウザは `localStorage`。

## 🗺 フローチャートで分岐を見る

**フローチャート** タブで、シーンと分岐の流れを図として確認できます。

- ノード＝シーン（青＝開始シーン、橙＝エンディング/🔒裏エンド）
- エッジ＝選択肢 / 条件分岐(真・偽) / シーン移動 / エンディング（ラベル付き）
- ノードをドラッグで整理、**ダブルクリックでそのシーンを編集**、ズーム/全体表示に対応

## 📂 プロジェクト一覧

**ファイル → 📂 プロジェクト一覧…** で、最近開いた/保存したプロジェクトを
アプリ内の一覧から選んで開けます（保存・読込時に自動で履歴に追加）。

## 🌐 ゲームをブラウザに書き出す

メニューの **ファイル → 🌐 ブラウザ(HTML)に書き出し…** で、作成したゲームを
単体の Web ページとして書き出せます。出力フォルダ内の **`index.html`** を
ブラウザで開けば、そのまま遊べます（インストール不要・配布も簡単）。

- 画像・BGM・SE・CG・フォント等のアセットは `assets/` に自動コピー・相対化されます。
- セーブ（10スロット）・システムデータはブラウザの `localStorage` に保存されます。
- 静的ファイルのみなので、GitHub Pages / Netlify 等にそのまま公開できます。

### ☁ Cloudflare Pages にそのままデプロイ（ZIP書き出し）

**ファイル → ☁ Cloudflare用ZIPに書き出し…** で、ZIP を生成します。
ZIP の **ルート直下に `index.html`** が入っているため、そのまま公開できます。

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages**
2. **Upload assets（直接アップロード）** を選択
3. 生成した ZIP（または展開した中身）をドラッグ＆ドロップ
4. **Deploy** で公開URLが発行されます

アセットには長期キャッシュ用の `_headers` も同梱されます。

書き出される内容:

```
出力フォルダ/
├── index.html      # これを開けば起動
├── game.js         # ゲームデータ（プロジェクト）
├── engine.js       # 実行エンジン（runtime.py のJS版）
├── player.js       # プレイヤーUI
├── style.css
└── assets/         # 画像・音声・フォント
```

## 📝 ブラウザ版エディタ（iPad などで編集）

PC（Windows/Mac）の本体だけでなく、**ブラウザだけで編集できる Web 版エディタ**
（`web/editor.html`）を同梱しています。**同じ `.nvproj` 形式**なので、
PCで作ったゲームを iPad 等のブラウザで読み込んで編集・テスト・書き出しできます。

できること:

- **開く(.nvproj)** … PCで作った（または以前保存した）プロジェクトを読み込み
- **編集** … シーン/コンポーネント（全20種）・キャラ・アイテム・変数・システム変数・
  ゲージ・背景・CG・BGM・SE・エンディング・設定をブラウザ上で編集
- **▶ テスト** … その場でプレイ（同じ実行エンジンを使用）
- **保存(.nvproj)** … iPad の「ファイル」に保存（ダウンロード）
- **⬇ HTML書き出し** … 画像/音声を埋め込んだ**単体HTML**を書き出して配布

> 画像・音声・フォントは、ブラウザ版では端末から取り込むとプロジェクトに
> 埋め込まれます（PCの絶対パスはブラウザでは読めないため、必要なら再取り込み）。

### 公開（GitHub Pages）

`.github/workflows/pages.yml` で **`web/` フォルダを GitHub Pages に公開** します
（リポジトリ設定で Pages のソースを「GitHub Actions」にしてください）。
公開後、iPad 等で **`https://<ユーザー>.github.io/<リポジトリ>/editor.html`** を
開けばエディタが使えます。ローカルで使う場合は `web/` を簡易サーバで配信します:

```bash
cd web && python3 -m http.server 8000   # → http://localhost:8000/editor.html
```

## 💿 本体を Mac DMG / Windows EXE に書き出す

ノベルメーカー本体を各OSの実行ファイルにパッケージできます。
詳しくは [`packaging/README.md`](packaging/README.md) を参照。

- **Mac:** `NovelMaker.app` →  **universal2 DMG**（Intel + Apple Silicon 両対応）
- **Windows:** `NovelMaker.exe`（ワンフォルダ / zip）

GitHub Actions（`.github/workflows/build.yml`）で、macOS / Windows / Linux 向けを
自動ビルドします。`v*` タグを push すると Release に成果物を添付します。

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm packaging/novelmaker.spec
```

## 🗂 プロジェクト構成

```
game-maker/
├── run.py                  # 起動ランチャー
├── requirements.txt
├── novelmaker/             # デスクトップアプリ本体（PySide6）
│   ├── app.py              # QApplication エントリ・テーマ
│   ├── mainwindow.py       # メインウィンドウ（エディタ⇔プレイヤー）・設定・プロジェクト一覧
│   ├── model.py            # データモデル・サンプルプロジェクト
│   ├── runtime.py          # ゲーム実行エンジン（Qt 非依存）
│   ├── save.py             # 10スロットセーブ・システムデータ・プロジェクト履歴
│   ├── exporter.py         # ブラウザ(HTML)/ZIP 書き出し
│   ├── condition_widget.py # 条件式ビルダー
│   ├── command_dialog.py   # コマンド編集ダイアログ
│   ├── scene_editor.py     # シーン＆コンポーネント編集（D&D並び替え）
│   ├── editors.py          # 各リソース編集タブ
│   ├── layout_editor.py    # レイアウト/画像/非表示 編集タブ
│   ├── flowchart.py        # フローチャートタブ
│   └── player.py           # プレイヤー（実行画面）
├── web/                    # ブラウザ書き出し用ランタイム
│   ├── index.html
│   ├── engine.js           # 実行エンジン（runtime.py のJS版）
│   ├── player.js           # プレイヤーUI
│   └── style.css
├── packaging/              # 配布ビルド（DMG / EXE）
│   ├── novelmaker.spec     # PyInstaller 設定
│   └── README.md
└── .github/workflows/
    └── build.yml           # Mac/Win/Linux 自動ビルド
```

## 💾 データ形式

プロジェクトは人間が読める JSON（`.nvproj`）で保存されます。同じ場所に
セーブデータ `<名前>.saves.json`、システムデータ `<名前>.system.json` が作られます。
古い形式のプロジェクトは読み込み時に自動で現行仕様へ移行されます。
